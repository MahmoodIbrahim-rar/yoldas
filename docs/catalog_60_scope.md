# Catalog 60 Scope

This file defines the next **24 reference recipes**. They are planned inputs, not yet public catalog entries. Each will be calculated from named, weighed USDA FoodData Central ingredients already used by the project; the resulting values will remain labelled as Yoldaş reference servings, not universal restaurant values. USDA FoodData Central is public-domain data under CC0 and asks users to cite it as the source. [1]

## Acceptance checks

Every input must include Arabic and Turkish names, search aliases, a serving weight, a weighed ingredient list, the FDC IDs generated by the existing build script, calculated macros, the standard reference disclaimer, and a successful search in both interface languages. No recipe is published if any ingredient source is missing.
