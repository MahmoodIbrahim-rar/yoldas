# تحقق حي بعد التحديث

نفّذ الخطوات بالترتيب من داخل مجلد المشروع الجديد فقط. لا تضف أي مفتاح جديد ولا تعدّل `config.js`.

## 1. تفعيل وضع الجيم

افتح Supabase → **SQL Editor**، وانسخ محتوى الملف التالي كاملًا ثم اضغط **Run**:

```text
supabase/gym-mode-setup.sql
```

## 2. نشر ميري ودليل الـ60 وصفة

من Command Prompt داخل مجلد المشروع اكتب:

```bat
npx supabase functions deploy health-assistant
```

بعد النشر اختبر زر **English** من صفحة الترحيب أو الشريط العلوي. تأكد أن اتجاه الصفحة يصبح يسارًا إلى يمين، ثم أنشئ خطة قصيرة أو أرسل رسالة لميري وتأكد أن الرد يظهر بالإنجليزية.

قبل النشر شغّل ملف `supabase/ai-usage-limits-setup.sql` مرة واحدة داخل SQL Editor. يفعّل حدًا يوميًا من 5 طلبات نصية لميري لكل حساب، مع بديل يدوي مفهوم عند بلوغ الحد.

## 3. اختبار سريع من حسابك الحقيقي

افتح الموقع عبر `localhost`، ثم:

1. من **الإعدادات** اختر أسلوب ميري الحماسي واحفظه.
2. من **اليوم → وضع الجيم** سجّل تمرينًا واحدًا ومجموعة واحدة بوزن وعدات حقيقيين.
3. اسأل ميري عن التمرين الذي سجلته. يجب أن تعتمد على السجل الحقيقي عندما يكون السؤال متعلقًا به، من دون اختراع تقدم.

لا تدخل أي بيانات شخصية أو صحية حساسة لأغراض الاختبار. لا تظهر أي بيانات لمستخدم آخر في وضع الجيم بسبب سياسات RLS الموجودة داخل ملف SQL.

## 4. تقاعد صور تقدم الجسم وحذفها نهائيًا

الميزة لم تعد موجودة في الواجهة أو داخل Miri. بعد رفع النسخة الجديدة وفتح الموقع بحسابك مرة واحدة، سيحذف الموقع صور جسمك القديمة وسجلاتها الخاصة تلقائيًا من حسابك لتوفير المساحة.

بعد ذلك فقط، افتح Supabase → **SQL Editor** وشغّل ملف المراجعة التالي:

```text
supabase/retire-progress-photos.sql
```

إذا ظهرت النتيجة `0`، يمكنك إزالة التعليق من أسطر الحذف داخل نفس الملف وتشغيلها في مرة ثانية لإزالة الجدول والبكت نهائيًا. هذا الحذف غير قابل للاسترجاع.

## 5. تفعيل بريد استرجاع كلمة السر

شغّل أولًا ملف الإعداد الجديد من Supabase → **SQL Editor**:

```text
supabase/friends-recovery-setup.sql
```

ثم انشر دالة الحساب المحدثة:

```bat
npx supabase functions deploy account-auth
```

قبل اختبار الرابط، أضف `https://bodibrahim-rar.github.io/` في Supabase → **Authentication → URL Configuration → Redirect URLs**. عند إنشاء حساب جديد يظهر **بريد الاسترجاع**. يظل الدخول باسم المستخدم وكلمة السر. للحسابات القديمة، افتح **الإعدادات** وأضف بريد الاسترجاع هناك. زر **نسيت كلمة السر؟** يرسل رابطًا إلى هذا البريد فقط ولا يعرض إن كان اسم المستخدم موجودًا أم لا.

## 6. تفعيل الأصدقاء وستريك الصور المؤقتة

بعد تشغيل ملف `friends-recovery-setup.sql` من الخطوة السابقة، انشر دالة الأصدقاء بهذا الأمر:

```bat
npx supabase functions deploy social-service --no-verify-jwt
```

من **المجتمع** ابحث عن صاحب باسم المستخدم الدقيق، ثم أرسل طلب صداقة. لا تظهر الصور إلا بعد قبول الطرفين. الستريك صورة JPG أو WebP حتى 2 ميجابايت، مرة واحدة يوميًا لكل صديق، وتنتهي تلقائيًا خلال 24 ساعة. يوجد حظر وإبلاغ، ولا يوجد بحث عام أو صور عامة.

بعد وصول ستريك لصديق، يستطيع المستلم فقط الضغط على أحد الردود الثلاثة القصيرة. تحقق أن الرد يظهر لطرفي الستريك ولا يستطيع حساب ثالث رؤيته أو إضافته.

## 7. تفعيل دعم الحافز الاختياري

شغّل محتوى الملف التالي مرة واحدة من Supabase → **SQL Editor**:

```text
supabase/motivation-support-setup.sql
```

من **الإعدادات** اكتب رسالة قصيرة حقيقية، ثم فعّل الموافقة على المشاركة المجهولة واحفظ. من **المجتمع** يمكن طلب رسالة داعمة. لا تختبر ذلك برسالة منسوبة لشخص آخر؛ الرسائل المعروضة يجب أن تكون رسائل وافق أصحابها الحقيقيون على مشاركتها.
