# نطاق دليل أكل Yoldaş المحلي — الإصدار الأول

## الهدف

يبني الدليل مرجعًا صغيرًا قابلًا للبحث للأكلات المصرية والتركية الشائعة. الغرض منه تقديم قيمة تغذوية موثقة لكل **حصة معرفة بوضوح**، وليس الادعاء بأن كل طبق منزلي أو مطعمي له رقم واحد ثابت.

## ما يُقبل في الدليل

كل سجل يحتاج إلى اسم عربي، واسم تركي عند توفره، ووصف حصة قابل للقياس، والطاقة بالكيلوكالوري للحصة أو لكل 100 غرام، ورابط مصدر، وتاريخ مراجعة. تحفظ الواجهة مصدر القيمة ليعرف المستخدم أن الرقم مرجعي وليس تخمينًا من المساعد.

| الحقل | القاعدة |
|---|---|
| الحصة | جرامات أو ملليلترات أو وحدة منزلية محددة مع وزن مرجعي |
| الطاقة | كيلوكالوري للحصة المحددة أو لكل 100 غرام من المصدر |
| المصدر | جهة رسمية أو قاعدة بيانات موثقة أو ملصق غذائي للمنتج |
| اللغة | العربية والتركية، مع اسم أصلي أو مرادف عند الحاجة |
| الحالة | موثّق، يحتاج مراجعة، أو مستبعد |

## ما يُستبعد مبدئيًا

لا تُضاف أطباق مثل الكشري، الشاورما، أو الدونر كرقم واحد عام إذا لم تتحدد الوصفة والحصة. يمكن إضافتها لاحقًا في صورة وصفات محددة أو منتجات مطاعم/علامات محددة، مع فصل واضح بين كل نسخة.

## الإطلاق المرحلي

يبدأ الإصدار الأول بـ 25 إلى 40 عنصرًا موثقًا عالي التكرار، ثم يتوسع إلى 100–150 عنصرًا بعد مراجعة المصادر. لا تُضاف قيمة رقمية لمجرد اكتمال القائمة.
