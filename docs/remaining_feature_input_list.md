# Remaining Feature Input List

The approved bundle contains only the following feature inputs.

| Feature | Inputs required from the user | Default privacy posture |
|---|---|---|
| Private progress photos | Image chosen explicitly by the user, optional capture date, optional private note | Private by default; no public sharing or automatic analysis |
| Temporary-context support | Short user-entered situation, optional end date, optional desired support level | Visible only to the account owner and Miri |
| Voice meal input | Explicit microphone recording started by the user | Review transcript before any meal is saved; do not retain raw audio unless the user elects to keep it |
| Spoken daily summary | Explicit button press; current user-owned daily logs only | Generate on demand; no background voice playback |
| Motivation support | Explicit opt-in, own message or predefined non-impersonating encouragement | No fake peers, rankings, or messages attributed to other people |

Not included in this bundle: further Miri-personality expansion or weekly community challenges.
