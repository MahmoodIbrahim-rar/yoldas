# فحص تبديل البيانات الوصفية المنشورة

في فحص GitHub Pages بتاريخ 2026-08-27، كان ملف `app.js` المنشور يحتوي بالفعل على `PAGE_META` و`updatePageMeta`. كما كانت الصفحة محمّلة في اللغة العربية، ولذلك كان عنوانها ووصفها العربيان ظاهرين عند الفحص الأولي.

بعد اختيار English، تحوّل محتوى الواجهة ووسم `html lang` إلى الإنجليزية، لكن ظل عنوان الصفحة ووصفها وOpen Graph وTwitter بالعربية. هذا يؤكد أن النسخة المنشورة تحتوي جدول البيانات ودالة التحديث، لكن دالة `applyLocale` المنشورة لا تستدعي `updatePageMeta()` في موضع التنفيذ الصحيح. يلزم فحص محتوى `app.js` المنشور بدقة وإصلاح الاستدعاء فقط.
