# Yoldaş — دليل التشغيل والتعديل (بالعربي)

نسخة بسيطة جدًا من Yoldaş: بدون React، بدون TypeScript، وبدون خطوة بناء (build). استخدم سيرفرًا محليًا بسيطًا عند تشغيل Supabase؛ لا تفتحها عبر `file://`.

## أي ملف أفتح لكل تعديل؟

| عايز تعدّل | افتح هذا الملف |
|---|---|
| النصوص والأزرار وترتيب الأقسام | `index.html` |
| الألوان والخطوط والتصميم والتجاوب | `style.css` (المتغيرات في أول الملف) |
| أي تفاعل: تسجيل الدخول، الماء، المحادثة، الخطط | `app.js` |
| رابط Supabase والمفتاح العام فقط | `config.js` |
| هيكل قاعدة البيانات والصلاحيات الأساسية | `supabase/schema.sql` |
| إضافة اسم المستخدم للحسابات | `supabase/account-setup.sql` |
| المساعد الذكي (الخادم الآمن) | `supabase/functions/health-assistant/index.ts` |

لا تضع أي مفتاح سرّي في أي ملف من ملفات الواجهة (`index.html`, `style.css`, `app.js`, `config.js`).

## ربط Supabase

1. افتح لوحة تحكم مشروعك في [supabase.com](https://supabase.com) → **Project Settings → API**.
2. انسخ:
   - **Project URL** (شكله: `https://xxxxxxxx.supabase.co`، بدون `/rest/v1` بعده).
   - **Publishable key** أو **anon public key** (وليس `service_role`).
3. افتح ملف `config.js` وضع القيمتين مكان القيم الفارغة:

```js
window.YOLDAS_CONFIG = {
  supabaseUrl: "https://xxxxxxxx.supabase.co",
  supabasePublishableKey: "المفتاح_العام_هنا",
  assistantFunction: "health-assistant"
};
```

4. من **Authentication → Providers**، فعّل **Anonymous Sign-Ins** إذا كنت تريد إتاحة زر التجربة المؤقتة بدون حساب.
5. من SQL Editor، شغّل محتوى `supabase/schema.sql` مرة واحدة (ينشئ الجداول وصلاحيات RLS، ولا يحذف أي بيانات).
6. انشر دالة المساعد (تحتاج [Supabase CLI](https://supabase.com/docs/guides/cli) مثبتة على جهازك):

```
supabase functions deploy health-assistant
```

7. ضع مفتاح Gemini كسرّ داخل Supabase فقط (وليس في أي ملف من ملفات الواجهة):

```
supabase secrets set GEMINI_API_KEY=مفتاحك_هنا
```

## تفعيل الحسابات باسم المستخدم وكلمة المرور

هذه النسخة تسمح للمستخدم بالدخول باسم مستخدم وكلمة مرور. كلمة المرور لا تُحفظ في أي ملف داخل المشروع؛ تُدار بشكل آمن داخل Supabase Auth. عند التسجيل يضيف المستخدم **بريد استرجاع خاص** لا يظهر للآخرين ويُستخدم فقط إذا نسي كلمة السر.

1. في Supabase افتح **Authentication → Providers → Email** ثم فعّل مزود **Email** واضبط رابط الموقع ضمن Redirect URLs.
   في **Authentication → URL Configuration → Redirect URLs** أضف رابط موقعك المنشور. للموقع الحالي استخدم:

   ```text
   https://bodibrahim-rar.github.io/
   ```

   لو غيّرت الدومين لاحقًا، أضف الدومين الجديد في نفس المكان قبل اختبار زر **نسيت كلمة السر؟**.
2. من **SQL Editor** شغّل محتوى الملف:

```text
supabase/account-setup.sql
```

3. من داخل مجلد المشروع شغّل أمر نشر دالة الحساب:

```bash
npx supabase functions deploy account-auth
```

4. المستخدم يختار اسمًا من 3 إلى 24 حرفًا إنجليزيًا صغيرًا أو رقمًا، ويمكن استخدام النقطة أو `_` أو `-`.

> مهم: يظل الدخول باسم المستخدم وكلمة السر. البريد خاص للاسترجاع فقط ولا يُعرض في المجتمع أو نتائج البحث. زر **نسيت كلمة السر؟** يعطي نفس الرسالة للحسابات الموجودة وغير الموجودة كي لا يكشف أسماء الحسابات.

## العربية والتركية

يوجد زر **العربية / Türkçe** في أعلى صفحة الترحيب وداخل لوحة المتابعة. الواجهة تتبدّل بين اللغتين، ويتحوّل اتجاه الصفحة تلقائيًا. طلبات المساعد والخطط الجديدة تحمل اللغة المختارة إلى الدالة، فيرد Gemini بالعربية أو التركية حسب اختيار المستخدم.

بعد استبدال ملفات المشروع بنسخة محدثة، انشر دالة المساعد مرة أخرى من داخل مجلد المشروع لكي يصل منطق اللغة الجديد إلى Supabase:

```bash
npx supabase functions deploy health-assistant
```

لا تحتاج إلى إعادة إضافة مفتاح Gemini، ولا إلى إعادة تشغيل ملف SQL الخاص بالحسابات إذا نفّذته بالفعل.

## Miri — مساعدة Yoldaş

اسم المساعدة الظاهر للمستخدم هو **Miri**. تظهر في شاشة المحادثة بترحيب أوضح وحالة تفكير باسمه، وتطلب دالة Gemini منها أسلوبًا دافئًا ومشجعًا مع اقتراح خطوة عملية قصيرة، من غير وعود صحية أو تشخيصات.

من **الإعدادات → أسلوب ميري**، يستطيع كل مستخدم اختيار نبرة داعمة ودافئة، أو هادئة ومباشرة، أو حماسية. النبرة تغيّر طريقة الصياغة فقط؛ لا تغيّر حدود الإرشاد الصحي ولا تجعل ميري تشخّص أو تعد بنتائج.

بعد استبدال المشروع بهذه النسخة، يكفي نشر دالة المساعد مرة واحدة لتظهر شخصية Miri في الردود الحية:

```bash
npx supabase functions deploy health-assistant
```

لا تحتاج إلى مفتاح Gemini جديد ولا إلى تشغيل SQL لهذه التعديلات.

### اللغات

تدعم Yoldaş الآن **العربية** و**Türkçe** و**English** من زري اللغة في صفحة الترحيب ولوحة المتابعة. العربية تستخدم اتجاه اليمين إلى اليسار، أما التركية والإنجليزية فتستخدمان اليسار إلى اليمين. عند اختيار English، تظهر واجهة الحساب واليوم والخطط والجيم ودليل الطعام والمجتمع بالإنجليزية، وتطلب الواجهة من Miri إنشاء الردود والخطط الجديدة أو ترجمة الخطط إلى الإنجليزية.

بعد استبدال الملفات، انشر `health-assistant` مرة واحدة ليصل دعم اللغة الإنجليزية إلى Miri والخطط:

```bat
npx supabase functions deploy health-assistant
```

### حدود Miri اليومية لحماية التكلفة

لمنع استهلاك Gemini بلا حد، يملك كل حساب **5 طلبات نصية من Miri يوميًا** في البداية. يشمل ذلك المحادثة وإنشاء خطة جديدة وترجمة خطة محفوظة. يتحقق الخادم من الحد، وليس المتصفح؛ وإذا فشل Gemini لا يُحسب الطلب الفاشل على المستخدم.

شغّل `supabase/ai-usage-limits-setup.sql` مرة واحدة داخل Supabase → **SQL Editor**، ثم انشر `health-assistant`. عند الوصول للحد، يبقى دليل الأكل والتسجيل اليدوي والماء والجيم متاحين، وتظهر رسالة تطلب تسجيل الوجبة من الدليل أو المحاولة في اليوم التالي.

### حفظ خطط Miri داخل الحساب

عند إكمال أسئلة **خطة أكل** أو **خطة تمرين** والضغط على إنشاء الخطة، تحفظ Miri الخطة داخل جدول `plans` مع معرف المستخدم نفسه. إذا أنشأ المستخدم خطة جديدة من النوع نفسه، تصبح الخطة السابقة من ذلك النوع غير نشطة بدل حذفها. وعند تسجيل الدخول إلى الحساب مرة أخرى، يجلب الموقع الخطط النشطة لهذا الحساب فقط.

تظهر في شاشة **اليوم** بطاقة خامسة باسم **الخطة النشطة**: تعرض خطة أكل، أو خطة تمرين، أو الاثنتين إذا كانتا نشطتين. لا تعرض البطاقة أي خطة تخص مستخدمًا آخر.

## دليل الأكل المصري والتركي المرجعي

يوجد داخل `data/reference_recipes.json` دليل من **60 وصفة**: 24 مصرية و24 تركية و12 وجبة يومية شائعة مثل البيض والخبز، الدجاج والأرز، المكرونة بالطماطم، العدس والأرز، والزبادي والخضار. افتح لوحة **اليوم** ثم اضغط **سجّل وجبة** للبحث عن وصفة، أو استخدم فلتر **وجبات يومية**. عند الضغط على أي وصفة تظهر المكونات الدقيقة للحصة المرجعية بأوزانها، والمغذيات، ثم يمكنك اختيار حجم الحصة وتسجيلها.

كل قيمة مكتوبة بوضوح على أنها **وصفة Yoldaş مرجعية بحصة تقريبية**، وليست رقمًا ثابتًا لكل مطعم أو طبخة منزلية. تظهر الحصة بالجرام، والسعرات، ومصدر حساب المكوّنات داخل تفاصيل الوصفة. الحسابات مبنية على بيانات [USDA FoodData Central](https://fdc.nal.usda.gov/) المتاحة تحت CC0؛ راجع `docs/reference_recipe_rules.md` و`docs/food_catalog_sources.md` قبل تعديل البيانات.

لا يحتاج هذا الدليل إلى مفتاح جديد أو SQL إضافي؛ يستخدم جدول `meals` الموجود لتسجيل الوجبة التي يختارها المستخدم. ولجعل ميري تستخدم جميع الوصفات الـ60 عند الحديث عن وجبة، انشر الدالة الموجودة بعد استبدال الملفات:

```bash
npx supabase functions deploy health-assistant
```

### إذا ظهرت رسالة «تعذر تسجيل الوجبة الآن»

لو كانت نسخة قاعدة البيانات قديمة وظهر خطأ عند الضغط على **سجّل هذه الوجبة**، افتح Supabase → **SQL Editor**، ثم شغّل محتوى الملف التالي مرة واحدة:

```text
supabase/meals-compatibility-setup.sql
```

الملف آمن للتشغيل المتكرر: لا يحذف أي وجبة أو حساب أو صورة. وظيفته إضافة الحقول الناقصة فقط إلى جدول الوجبات وإعادة تفعيل وصول كل مستخدم لوجباته وحده.

## وضع الجيم

من لوحة **اليوم** اضغط **وضع الجيم**، ثم اكتب اسم التمرين ورقم المجموعة والعدات والوزن. يعرض الموقع آخر المجموعات وأفضل وزن مسجل لكل تمرين من بيانات المستخدم نفسه فقط. عند ارتباط السؤال بالجيم، تستطيع ميري قراءة السجل الحقيقي وتشجيع أي تحسن موجود فيه من دون اختراع أرقام أو تقدم.

قبل استخدام زر تسجيل المجموعة، افتح Supabase → **SQL Editor**، ثم انسخ محتوى هذا الملف كاملًا وشغّله مرة واحدة:

```text
supabase/gym-mode-setup.sql
```

بعد نجاح SQL، انشر دالة المساعد من داخل مجلد المشروع:

```bash
npx supabase functions deploy health-assistant
```

لا تحتاج إلى مفتاح Gemini جديد. الجداول الجديدة محمية بسياسات تجعل كل مستخدم يرى جلساته ومجموعاته فقط.

## تقاعد صور تقدم الجسم

تمت إزالة ميزة صور تقدم الجسم ورأي Miri في الصورة لتوفير مساحة Supabase. عند فتح النسخة الجديدة بحساب المستخدم، يحذف التطبيق صور الجسم القديمة وسجلاتها الخاصة لذلك الحساب مرة واحدة. بعد تحققك من أن عدد السجلات أصبح صفرًا، استخدم `supabase/retire-progress-photos.sql` لإزالة الجدول والبكت نهائيًا. الحذف غير قابل للاسترجاع.

## الأصدقاء وستريك الصور المؤقتة

المجتمع صار مبنيًا على أصدقاء يختارهم المستخدم، وليس على بحث عام أو صور عامة. البحث يتم باسم المستخدم الدقيق فقط، وكل طلب يحتاج موافقة الطرفين. صور الستريك JPG أو WebP حتى 2 ميجابايت، صورة واحدة يوميًا لكل صديق، وتنتهي تلقائيًا خلال 24 ساعة. توجد إزالة صديق وحظر وإبلاغ، ولا تصدر روابط الصور إلا لطرفي الصداقة.

شغّل `supabase/friends-recovery-setup.sql` مرة واحدة داخل SQL Editor، ثم انشر:

```bash
npx supabase functions deploy social-service --no-verify-jwt
```

يمكن لمستلم الستريك اختيار رد واحد سريع فقط: **جامد** أو **كمل** أو **فخور بيك**. لا توجد دردشة عامة أو ردود من مستخدم غريب، وتختفي التفاعلات مع الستريك عند تنظيفه بعد انتهاء مدته.

## دعم الحافز الاختياري

من شاشة **الإعدادات** تستطيع كتابة رسالة دعم قصيرة ثم اختيار مشاركة الرسالة **بدون اسمك**. شاشة المجتمع تعرض رسائل اختار أصحابها مشاركتها فقط؛ لا توجد حسابات أو رسائل أو ترتيب وهمي. قبل أول استخدام فقط، افتح Supabase → **SQL Editor**، وانسخ محتوى هذا الملف كله ثم اضغط **Run**:

```text
supabase/motivation-support-setup.sql
```

يمكنك إلغاء علامة المشاركة في أي وقت؛ تظل الرسالة خارج مساحة الدعم، ولا يظهر اسمك فيها في أي حال.

## مساحات الإعلان الجاهزة

صفحة الترحيب تحتوي على مساحتين جانبيتين بلون دافئ تظهران على الشاشات العريضة فقط، وتحملان معرّفي `welcome-left-rail` و`welcome-right-rail`. لا يوجد أي إعلان أو كود Google داخل النسخة الآن، ولذلك لا يجري تحميل أي خدمة إعلانية ولا جمع بيانات إعلانية.

عند قرار تشغيل الإعلانات لاحقًا، أضف كود Google AdSense الرسمي بعد امتلاك حساب مُوافق عليه ومراجعة سياسة الخصوصية وموافقة ملفات الارتباط المناسبة لجمهورك. لا تستبدل المساحات الحالية بصور إعلانات وهمية أو إعلانات غير مصرح بها.

## تشغيل محلي بسيط

لا تفتح `index.html` بالنقر المزدوج أو عبر رابط `file://` عند استخدام Supabase، لأن المتصفح قد يمنع الاتصال. شغّل سيرفرًا ثابتًا بسيطًا من داخل مجلد المشروع:

```
python3 -m http.server 5500
```

ثم افتح `http://localhost:5500` في المتصفح.

## تغيير الهوية البصرية

كل الألوان موجودة كمتغيرات في أول ملف `style.css` تحت `:root`. غيّر القيم هناك فقط، وسيتغيّر التصميم كله تلقائيًا.

## بدون إعداد Supabase؟

الموقع يفتح ويعرض صفحة الترحيب بشكل طبيعي، لكنه سيعرض رسالة عربية واضحة عند الضغط على "ابدأ رحلتي مجانًا" بدل الانهيار، ويطلب منك إكمال الإعداد أعلاه.

## للمزيد

راجع `VALIDATION.md` لمعرفة ما تم اختباره فعليًا، وما يحتاج إعدادك الخاص لـ Supabase ليعمل.
